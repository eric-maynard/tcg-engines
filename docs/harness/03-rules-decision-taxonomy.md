## 1. Decision taxonomy

Legend for **When**: PRE = pregame; ACT = discretionary action with priority; FIN = finalization of a chain item (rules 355–358 / 402–405); RES = during resolution (355.17, 383.3.a.3, 740.4.a.1); PAY = pay-costs step (357/404); CLN = cleanup/task; CMB = combat damage step; RPL = when a replacement would apply; ANY = regardless of priority (312.1.b.1 Limited-action prompts).

## 2. Compound cases

**A. The play-time bundle (one atomic "play" = rules steps 354–359).** Everything below is committed before anyone can respond and (except via 750–755) cannot be changed (355.15):
1. card + source zone (D3) and alt/base cost selection (D4: Flow, "play me for X", Hidden-for-0);
2. as-played choices (355.1): optional additional costs incl. Accelerate, each Repeat instance/tier, XP/discard/kill/exhaust/spend-buff options, variable-count costs (D6, D7), as-played enum/name (Ivern, The List, D43);
3. unit play location (D5) — interacts with (2): Dragon Roost / Stalking Wolf change legal locations only if the cost is paid; Ambush location grants Reaction timing (822.1.b) so timing legality depends on the location pick;
4. modes (D11) — with Repeat: one mode per execution, ordered, possibly "not already chosen";
5. targets for every instruction and every Repeat execution (D12–D17), move destinations (D18); Hidden-origin restricts targets to that battlefield per-target (811.1.d.2);
6. total cost determination incl. Deflect per target-choice (809), discount order (D10);
7. payment (D8 objects, D9 resource plan incl. mid-payment Add-Reactions).
Legality is checked only at step 5 (358); failure rewinds everything (358.5). 355.16/357.3 forbid choices that deterministically make later steps illegal. Recommendation: model `PlayAction` as a single structured answer with nested optional fields, validated as a whole, *or* as a scripted sub-dialog of Decisions that is transactional (rollback on 358.5).

**Triggered abilities are different**: their targets/modes/optional-perform/costs are chosen when *the trigger* finalizes (355.5.b, 402), not when the permanent was played — so "When you play me, kill a unit" prompts after the unit resolves, in a Closed state, possibly on another player's turn.

**B. Resolution-time prompts** (355.17 catch-all): D19 integer X, D22/D23 optional instructions and mid-effect pays, D24/D25/D26 forced and delegated choices, D28/D29 hidden-info picks and ordering, D15/D17 re-selection/allocation, D30 nested plays (which spawn new pending items and their own FIN dialogs while the parent is still resolving — 354.3/401.2 say finish the current resolution first, then finalize the new pending items oldest-first, 337.1), D42 new choices. Reflexive "do this (N times)" (387–388) creates N new chain items, each with its own FIN targeting (e.g. ogn-005 Disintegrate, sfd-198 Arise!, unl-192 Alpha Strike "for each unit this kills, do this").

**C. Replacement "instead" decisions** (D31/D32) occur at the moment of the would-be event with no priority window: inside cleanups (deaths from combat), inside cost payment (357.2.a — cost still counts as paid), inside draws/reveals (Nocturne, Void Hatchling, Undertitan), token plays (Zilean), scoring (Otterpus mandatory, Brush optional swap-back). Mandatory ones (Zhonya's, Symbol of the Solari, Endless Riches, Gangplank Naval, Highlander/Tactical Retreat once targeted) need no prompt but still need D32 ordering when several match. "Once each turn … you may" must track declined-doesn't-consume (371.2.b).

**D. Simultaneous triggers** (D33/D34): batch per event; each controller submits a permutation of their own triggers; controllers processed in turn order starting with Turn Player (383.3.d.1); combat-start chain uses attacker → others → defender (464.2.e.1). Then each pending item finalizes oldest-first (337.1) with its own D20/D21/D11/D12 prompts. Chain resolution afterwards is LIFO, so the *last* placed resolves first — ordering is strategically meaningful.

**E. Combat sequence** (463–466): Turn Player picks which staged combat (D36) → showdown opens, attacker gets Focus (464.2.d) → attack/defend triggers ordered (D33) → alternating Focus/Priority play (D1/D2) → all pass → damage step: attacker's full assignment (D37), then defender's (D37), with per-unit replacement ordering by that unit's controller interleaved (465.2.c.5) → damage dealt simultaneously → Combat Cleanup (deaths → Deathknell ordering D33, optional death replacements D31) → result/conquer triggers (D33) → possibly re-stage (466.3.d.1).
